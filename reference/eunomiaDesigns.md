# eunomiaDesigns

Patient-Level Prediction Model Designs for the Eunomia dataset

## Usage

``` r
eunomiaDesigns
```

## Format

An object of class `list` of length 5.

## Details

A prespecified list containing model designs with class \`modelDesign\`
as generetated by \`PatientLevelPrediction::createModelDesign\` See
[createModelDesign](https://ohdsi.github.io/PatientLevelPrediction/reference/createModelDesign.html)
for more details and
<https://ohdsi.github.io/PatientLevelPrediction/articles/BuildingMultiplePredictiveModels.html#creating-a-model-design>
on examples how to create a model design.
