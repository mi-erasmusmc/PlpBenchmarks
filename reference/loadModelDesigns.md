# Loads the model design list

Loads the models design list.

## Usage

``` r
loadModelDesigns(designs = "all")
```

## Arguments

- designs:

  Define which designs should be loaded. Choice of "all" to load all
  tasks or a numeric vector to define which.

## Details

A model design is an object of class \`modelDesign\` as generated by
\`PatientLevelPrediction::createModelDesign()\`.
