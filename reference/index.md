# Package index

### View tasks

View pre-specified tasks for real-world data mapped to the OMOP-CDM and
the Eunomia dataset.

- [`tasks`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/tasks.md)
  : tasks
- [`modelDesigns`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/modelDesigns.md)
  : modelDesigns
- [`eunomiaTasks`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/eunomiaTasks.md)
  : eunomiaTasks
- [`eunomiaDesigns`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/eunomiaDesigns.md)
  : eunomiaDesigns

### Create a benchmark design

Create a benchmark design and inspect it.

- [`createBenchmarkDesign()`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/createBenchmarkDesign.md)
  : Create a benchmark analysis design
- [`viewBenchmarkSettings()`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/viewBenchmarkSettings.md)
  : View settings of a benchmark design

### Create cohorts, extract data

Create cohorts on an OMOP-CDM instance and extract data from the CDM.

- [`createBenchmarkCohorts()`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/createBenchmarkCohorts.md)
  : Instantiates a set of cohorts
- [`extractBenchmarkData()`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/extractBenchmarkData.md)
  : Extract the data for the benchmark

### Run a benchmark

Run the benchmark design and view results.

- [`runBenchmarkDesign()`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/runBenchmarkDesign.md)
  : Run the benchmark models.
- [`getBenchmarkModelPerformance()`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/getBenchmarkModelPerformance.md)
  : Get the mode performance.
- [`viewBenchmarkResults()`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/viewBenchmarkResults.md)
  : View a shiny app with the benchmark results
