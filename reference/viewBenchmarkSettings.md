# View settings of a benchmark design

Provides the settings as a data frame for side-to-side comparisons.

## Usage

``` r
viewBenchmarkSettings(benchmarkDesign)
```

## Arguments

- benchmarkDesign:

  A list of class `modelDesign` created using
  [`PLPBenchmarks::createBenchmarkDesign()`](https://mi-erasmusmc.github.io/PlpBenchmarks/reference/createBenchmarkDesign.md)
